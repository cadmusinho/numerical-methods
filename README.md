# numerical-methods
File Optimization.cpp contains many useful methods for solving real problems in a numerical way. The functions use objects of the Matrix and Solution classes, the codes of which have been made available to students for teaching purposes.

The methods contained in the file:
- expansion
- Fibonacci search method
- Lagrange search method
- Hooke-Jeeves method
- Rosenbrock method
- penalty function
- Nelder-Mead simplex
- steepest descent method
- conjugate gradient method
- Newton method
- golden ratio method
- Powell's method
